This is my first project foor the CS50x Harvard course, Its a recreate of chicken cross using scratch.

~Description:
Its a simple classic game of chicken cross the road, 
i used a Hen from scratch default spirits and a downloaded car png as the cars.
The cars dont have a set speed as it was set to randomly choose between 0-10,
theres two levels to this game easy and hard, as you cross the white line in the middle the mode automatically sets to hard,
The car speeds are faster but the Hens speed is faster by 0.5 as i felt that it was unbeatable on default speed.
you can use the arrows to navigate right to go forward 2 steps and left to go back,
up and down using the arrows was set as well to give the player more freedom.
